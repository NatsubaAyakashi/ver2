# TRPG ログ整形ツール (Ver2)

ココフォリアなどの TRPG ログを色付き HTML に整形するツールです。タブごとの背景色・ボーダー色、発言者ごとの文字色を自由に設定できます。

---

## 🚀 はじめ方（exe ユーザー向け）

### 1. ツールを起動
`TRPGLogFormatter.exe` をダブルクリックして起動します。

### 2. ログファイルを読み込む
ウィンドウの最上部にある **「ログファイルを選んで解析」** ボタンをクリックします。

```
[ログファイルを選んで解析]  [色・設定]  [整形済みHTMLを保存]
```

ファイル選択ダイアログが開くので、整形対象の HTML ファイルを選択してください。

### 3. 色を設定する
**「色・設定」** ボタンをクリックして色設定ダイアログを開きます。

#### タブ色・ボーダー設定
各タブについて、以下が設定できます：
- **背景色**: タブの背景色（デフォルト：白 `#ffffff`）
- **ボーダー色**: タブの枠線の色（デフォルト：灰色 `#999999`）

色をクリックするとカラーピッカーが開きます。好きな色を選んでください。

#### 発言者の色設定
- 出現回数の多い上位 10 人は **「プレイヤー色」** セクションに表示されます。
- 低頻出の発言者は **「詳細 - 低頻出プレイヤー」** セクション（デフォルトで折りたたまれています）に表示されます。

各発言者の色を設定できます。

#### 設定を保存
**「保存」** ボタンをクリックすると設定が確定します。

### 4. 整形済み HTML を保存
**「整形済みHTMLを保存」** ボタンをクリックします。

保存先ダイアログが開きます。好きなフォルダと名前を指定して、**「保存」** をクリックしてください。

整形済みの HTML ファイルが生成されます。ブラウザで開いて確認できます。

## ❓ よくある質問（FAQ）

### Q. 起動したら「Python is not installed」と出ました
A. このツールは exe で単独動作するため、Python をインストールする必要はありません。
   別のアプリケーションか、リポジトリから Python 環境で実行している可能性があります。

### Q. ログファイルを選んでも何も起きません
A. ファイル形式を確認してください。このツールは **HTML ファイル**のみに対応しています。
   ココフォリアから「ログをダウンロード」で取得した HTML ファイルを選択してください。

### Q. 色が反映されていません
A. 以下をご確認ください：
   - タブ名やプレイヤー名の表記が一致しているか（例：`塩` と `[塩]` は別物です）
   - 色設定後に **「保存」** ボタンを押したか
   - 出力 HTML が古いバージョンになっていないか（ブラウザのキャッシュをクリアしてください）

### Q. 低頻出プレイヤーをすべて見たい
A. **「詳細 - 低頻出プレイヤー」** セクションの **[+]** ボタンをクリックして展開してください。

### Q. 背景色やボーダー色の初期値を変えたい
A. 現在はツール内で設定できません。ソースコードをカスタマイズしてください（開発者向けセクション参照）。

### Q. 複数のファイルを一度に処理したい
A. 現在はこのツールで同時処理できません。ファイルごとに個別に処理してください。

## 💻 開発者向けノート

このセクションは、ソースコードをカスタマイズする開発者向けです。

### ファイル構成
- `main.py`: メインウィンドウの UI
- `controller.py`: ファイル選択・解析・出力の制御
- `settings.py`: 色設定ダイアログ
- `renderer.py`: HTML の整形・スタイル生成
- `config.py`: 設定値（タブ、プレイヤー、色）
- `analyzer/analyzer.py`: HTML 解析ロジック

### 仕組み
1. **HTML 解析**: `analyzer/analyzer.py` の `extract_players_and_tabs()` がログを解析し、タブ名と発言者名を抽出します。
2. **色設定**: ユーザーが設定した色は `config` に保存されます（メモリ上のみ）。
3. **HTML 生成**: `renderer.py` の `build_formatted_html()` が CSS を生成して、色を適用した HTML を出力します。

### カスタマイズ例

#### タブのデフォルト背景色を変更
`config.py` で以下の行を変更します：

```python
"tab_default_background": "#f0f0f0",  # 薄いグレーに変更
```

#### プレイヤーのデフォルト色を追加
`controller.py` で人数判定や色割り当てロジックをカスタマイズできます。
